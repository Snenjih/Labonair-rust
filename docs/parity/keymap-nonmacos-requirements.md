# Pinned Linux and Windows Keymap Requirements

**Status:** Static non-macOS profile bindings and default-map block metadata inventoried; semantics and platform runtime acceptance remain open
**Baseline:** Zed commit `3569541038dd51524b03998ba4d38d253cb54f80`
**Platforms:** Linux and Windows
**Owner:** Keymap, with each action's canonical capability owner

This independently written register complements the [default platform action register](action-requirements.md) and the [macOS layer register](keymap-overlay-requirements.md). It inventories the six non-macOS base-profile overlays, the shared non-macOS override layer, and block-level key-equivalent flags for both default platform maps. Each overlay binding row preserves its key sequence, context, key-equivalent setting, action identifier, arguments, and explicit null state. The same overlay row applies to both platforms, but its dispatch must be verified separately on Linux and Windows.

## Layer composition and platform options

The platform default map is selected first. A selected base-profile overlay and the shared Vim/Helix layer may add or shadow bindings; the shared non-macOS override layer follows, with user bindings last. The pinned Linux runtime confirms action registration and declared aliases only. It does not prove a Linux key dispatch, and it provides no Windows runtime evidence.

The non-macOS selector has seven listed choices: Zed, VS Code, Atom, JetBrains, Sublime Text, Emacs, and Cursor. The `TextMate` variant exists in the pinned typed setting but is absent from this selector and has no non-macOS overlay asset. The `None` variant is also absent from the selector and disables built-in layers. Confirm how each value is exposed, saved, reloaded, and resolved at runtime. Windows uses the non-macOS base-profile overlays while retaining its own default platform map.

The `vim.json` layer is shared across platforms. Its 894 binding entries, eight explicit null bindings, 437 action identifiers, and per-binding requirements are recorded once under `KMP-MODE-VIM-HELIX` and `KEYBIND-VIM-HELIX-*` in the [macOS layer register](keymap-overlay-requirements.md); verify those rows on Linux and Windows separately.
