# Agent Handoff Template

Use this structure when returning a change to a maintainer or another agent.

## Outcome

```text
Summary:
Owner:
Canonical crate:
Active task:
Current status:
Target status:
```

## Changes

```text
Changed files and purpose:
Contracts updated:
Adapters/consumers updated:
Commands/surfaces updated:
Persistence/settings updated:
Notifications/events updated:
Obsolete paths removed:
```

## Evidence

```text
Focused tests:
Integration/workspace tests:
Documentation checks:
Dependency/architecture checks:
Visual evidence:
Security evidence:
Performance evidence:
Release evidence:
```

## Remaining work

```text
Known limitations:
Failed gates:
Unavailable gates and environment:
Pending evidence:
Remaining migration edges:
Next safe task:
```

Do not describe a target rule as current evidence. Link to the exact source,
test, artifact, or task that supports each important claim.
